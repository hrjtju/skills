# 文献调研工作流（批量场景）

当用户面对"导师让把这个方向的文献都看看"这类任务时，用三遍法做分级处理。

## 步骤

1. **检索建池**：用学术搜索引擎（如 Google Scholar、PubMed）按关键词找到 10–20 篇候选；优先近期高引综述和顶会/顶刊论文，可用"被引数 + 年份"过滤。
2. **第一遍批量过筛**（每篇 5–10 分钟）：只读 Abstract / Introduction / Figures / Conclusion，三问筛选，分成三档：
   - 相关且重要 → 进入第二遍
   - 可能相关 → 标记待复查
   - 不相关 → 直接丢弃（占大多数，这是正常的）
3. **第二遍归类整理**：对留下的论文做内容级阅读，按主题 / 方法路线分组，形成文献地图（谁和谁一派、关键分歧点在哪）。
4. **第三遍只给核心论文**：挑 3–5 篇与自己课题最相关的做审稿式精读，产出批判笔记。
5. **缺口定位**：从第三遍的"下一步研究"清单里提炼研究缺口（research gap），作为选题或综述立论依据。

## 加速技巧
- 用一篇高质量综述代替数十篇第一遍筛选——综述帮你做了初筛。
- 对候选论文，先看其被哪些后续工作引用、引用语境是褒是贬。
- 记录每篇论文的处理状态（已筛 / 二遍 / 精读），避免重复劳动。

## 反模式（提醒用户避免）
- 从第一篇开始逐字精读所有候选论文。
- 读困了就硬撑 Methods——那是第一遍没做好，该筛掉的没筛掉。
- 只记笔记不归类——读完一堆却说不清领域格局。

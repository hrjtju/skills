# PlotNeuralNet skill

## Overview

PlotNeuralNet is a Python + LaTeX/TikZ tool for drawing publication-quality neural network architecture diagrams. The user describes the architecture, and this skill generates Python code using the PlotNeuralNet API, compiles it to PDF, and opens the result.

- **Repo**: `https://github.com/HarisIqbal88/PlotNeuralNet`
- **Local path**: `/Users/heruijie/PlotNeuralNet/`
- **Requires**: Python 3, `pdflatex` (already installed at `/Library/TeX/texbin/pdflatex`)

## Architecture

```
/Users/heruijie/PlotNeuralNet/
├── pycore/tikzeng.py    # Core API: layer functions (to_Conv, to_Pool, etc.)
├── pycore/blocks.py     # Higher-level block functions (block_2ConvPool, etc.)
├── layers/              # TikZ style files (Box.sty, Ball.sty, etc.)
├── examples/            # LaTeX example architectures
├── pyexamples/          # Python example architectures
└── generate.py          # Wrapper script (generated by this skill)
```

## API Reference

All API functions are in `pycore/tikzeng.py` and `pycore/blocks.py`.

### Document structure (mandatory)

```python
from pycore.tikzeng import *
from pycore.blocks import *

arch = [
    to_head('..'),    # path to layers/ dir (relative from output .tex)
    to_cor(),         # color definitions
    to_begin(),       # begin tikzpicture
    # ... layers and connections ...
    to_end()          # end tikzpicture
]
```

### Layer functions (tikzeng.py)

```python
# Convolutional layer
to_Conv(name, s_filer=256, n_filer=64, offset="(0,0,0)", to="(0,0,0)", width=2, height=40, depth=40, caption=" ")

# Conv+Conv+ReLU bottleneck
to_ConvConvRelu(name, s_filer=256, n_filer=(64,64), offset="(0,0,0)", to="(0,0,0)", width=(2,2), height=40, depth=40, caption=" ")

# Pooling layer
to_Pool(name, offset="(0,0,0)", to="(0,0,0)", width=1, height=32, depth=32, opacity=0.5, caption=" ")

# UnPooling layer (decoder)
to_UnPool(name, offset="(0,0,0)", to="(0,0,0)", width=1, height=32, depth=32, opacity=0.5, caption=" ")

# Residual convolution block
to_ConvRes(name, s_filer=256, n_filer=64, offset="(0,0,0)", to="(0,0,0)", width=6, height=40, depth=40, opacity=0.2, caption=" ")

# Softmax layer
to_SoftMax(name, s_filer=10, offset="(0,0,0)", to="(0,0,0)", width=1.5, height=3, depth=25, opacity=0.8, caption=" ")

# Conv + Softmax
to_ConvSoftMax(name, s_filer=40, offset="(0,0,0)", to="(0,0,0)", width=1, height=40, depth=40, caption=" ")

# Element-wise sum (for skip connections)
to_Sum(name, offset="(0,0,0)", to="(0,0,0)", radius=2.5, opacity=0.6)

# Input image
to_input(pathfile, to='(-3,0,0)', width=8, height=8, name="input")
```

### Connection functions (tikzeng.py)

```python
# Forward connection (arrow from of-east to to-west)
to_connection(of="layer1", to="layer2")

# Skip connection (curved copy arrow)
to_skip(of="layer1", to="layer2", pos=1.25)
```

### Block functions (blocks.py)

```python
# Conv→ReLU→Pool block (encoder)
block_2ConvPool(name, botton, top, s_filer=256, n_filer=64, offset="(1,0,0)", size=(32,32,3.5), opacity=0.5)

# UnPool→Conv→Conv block (decoder)  
block_Unconv(name, botton, top, s_filer=256, n_filer=64, offset="(1,0,0)", size=(32,32,3.5), opacity=0.5)

# Residual block (N conv layers)
block_Res(num, name, botton, top, s_filer=256, n_filer=64, offset="(0,0,0)", size=(32,32,3.5), opacity=0.5)
```

### Spatial positioning

- Layers are positioned in 3D space using `(x, y, z)` offsets
- `x` = left-right, `y` = up-down, `z` = depth (into page)
- `to` = reference anchor point, e.g., `(conv1-east)` means "to the right of conv1"
- Connections draw from `<name>-east` to `<name>-west`
- Skip connections use `<name>-southeast` / `<name>-northeast`
- Typical x-offset between layers: `(1,0,0)` for close, `(2,0,0)` for more space
- Height/depth decrease in deeper encoder layers, increase in decoder

## Workflow

### 1. Understand the user's architecture

Ask clarifying questions if needed:
- What type of network? (CNN, FCN, U-Net, ResNet, custom)
- How many layers and what types?
- Any skip connections?
- Input/output dimensions?
- Any specific names or annotations?

### 2. Generate the Python script

Write a Python script to `/tmp/plot_nn_arch.py` using the API above. Always use `sys.path.insert(0, '/Users/heruijie/PlotNeuralNet')` so it can import from pycore.

The script must follow this pattern:
```python
import sys
sys.path.insert(0, '/Users/heruijie/PlotNeuralNet')
from pycore.tikzeng import *
from pycore.blocks import *

arch = [
    to_head('/Users/heruijie/PlotNeuralNet'),
    to_cor(),
    to_begin(),
    # ... architecture definition ...
    to_end()
]

def main():
    import os
    namefile = os.path.splitext(os.path.basename(__file__))[0]
    to_generate(arch, '/tmp/' + namefile + '.tex')

if __name__ == '__main__':
    main()
```

### 3. Compile to PDF

```bash
cd /tmp && python3 /tmp/plot_nn_arch.py && pdflatex -interaction=nonstopmode /tmp/plot_nn_arch.tex && rm -f /tmp/plot_nn_arch.aux /tmp/plot_nn_arch.log
```

### 4. Open the PDF

```bash
open /tmp/plot_nn_arch.pdf
```

## Naming conventions

- Layer names: descriptive lowercase with underscores (e.g., `conv1`, `pool2`, `upconv3`)
- Block names: prefix with block type (e.g., `b1`, `b2`, `b3`)
- Anchor references: `<name>-east` for right side, `<name>-west` for left side

## Common patterns

### Simple CNN (Conv → Pool → Conv → Pool → FC)

```python
to_Conv("conv1", 512, 64, offset="(0,0,0)", to="(0,0,0)", height=64, depth=64, width=2),
to_Pool("pool1", offset="(0,0,0)", to="(conv1-east)"),
to_connection("conv1", "pool1"),
to_Conv("conv2", 128, 64, offset="(1,0,0)", to="(pool1-east)", height=32, depth=32, width=2),
to_connection("pool1", "conv2"),
to_Pool("pool2", offset="(0,0,0)", to="(conv2-east)", height=28, depth=28, width=1),
to_connection("conv2", "pool2"),
to_SoftMax("soft1", 10, "(1,0,0)", "(pool2-east)", caption="FC"),
to_connection("pool2", "soft1"),
```

### U-Net (encoder-decoder with skip connections)

```python
# Encoder blocks
*block_2ConvPool(name='b1', botton='input', top='pool1', s_filer=256, n_filer=64, offset="(1,0,0)", size=(40,40,3.5), opacity=0.5),
*block_2ConvPool(name='b2', botton='pool1', top='pool2', s_filer=128, n_filer=128, offset="(1,0,0)", size=(32,32,3.5), opacity=0.5),
# Bottleneck
to_ConvConvRelu(name='bottleneck', s_filer=64, n_filer=(256,256), offset="(2,0,0)", to="(pool2-east)", width=(5,5), height=20, depth=20, caption="Bottleneck"),
to_connection("pool2", "bottleneck"),
# Decoder blocks
*block_Unconv(name="d2", botton="bottleneck", top='up2', s_filer=128, n_filer=128, offset="(2.1,0,0)", size=(32,32,3.5), opacity=0.5),
to_skip(of='ccr_b2', to='ccr_res_d2', pos=1.25),
*block_Unconv(name="d1", botton="up2", top='up1', s_filer=256, n_filer=64, offset="(2.1,0,0)", size=(40,40,3.5), opacity=0.5),
to_skip(of='ccr_b1', to='ccr_res_d1', pos=1.25),
```

### ResNet style (skip connections over pairs of layers)

```python
to_Conv("conv1", 64, 64, offset="(0,0,0)", to="(0,0,0)", height=32, depth=32, width=2),
*block_Res(2, "res1", "conv1", "res1_out", s_filer=64, n_filer=64, size=(32,32,3.5)),
*block_Res(2, "res2", "res1_out", "res2_out", s_filer=128, n_filer=128, size=(16,16,3.5)),
```

## Troubleshooting

- **"File layers/init.tex not found"**: Make sure `to_head()` receives the correct path to the PlotNeuralNet root (use absolute path `/Users/heruijie/PlotNeuralNet`)
- **PDF looks wrong**: Check spatial offsets; layers may be overlapping. Increase x-offset or adjust height/depth.
- **Missing blocks import**: Add `from pycore.blocks import *` when using `block_*` functions.
- **pdflatex errors**: Check for unescaped special characters in labels/captions (use LaTeX escaping).
